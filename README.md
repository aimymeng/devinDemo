# 企业主页项目

## 项目概述
这是一个基于React的企业官网项目，包含公司简介、招聘公告、招聘职位等核心页面。项目采用现代化的UI设计，响应式布局，确保在不同设备上都有良好的显示效果。

## 技术栈
- 前端框架：React 16
- UI组件库：Ant Design 4
- 样式处理：Less
- 网络请求：Axios
- 开发模式：函数组件 + Hooks
- 构建工具：Webpack 5

## 功能模块
1. **首页**
   - 导航菜单
   - Banner轮播
   - 公司概况
   - 活动介绍

2. **专项报名**
   - 报名表单
   - 活动详情

3. **人才政策**
   - 政策列表
   - 政策详情

4. **人才需求**
   - 职位列表
   - 职位筛选
   - 职位详情

## 项目结构
```
src/
├── components/           # 组件目录
│   ├── banner/           # Banner组件
│   ├── navigation/       # 导航组件
│   ├── footer/           # 底部组件
│   └── jobTable/         # 职位表格组件
├── pages/                # 页面目录
│   ├── index/            # 首页
│   ├── about/            # 专项报名
│   ├── jobs/             # 人才需求
│   └── recruitment/      # 招聘公告
├── public/               # 公共资源
│   └── images/           # 图片资源
└── utils/                # 工具函数
```

## 开发指南

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm start
```

### 构建生产版本
```bash
npm run build
```

## 代码规范
- 使用函数组件和Hooks，避免类组件
- 使用命名导出，避免默认导出
- 组件结构遵循单一职责原则
- 使用JSDoc风格的注释
- 工具函数使用camelCase命名
- CSS类名使用kebab-case命名
- 图片资源使用kebab-case命名

## 样式开发规范
- 使用Less预处理器编写样式
- 页面级样式放在对应页面组件同级目录下
- 组件级样式放在组件同级目录下
- 使用嵌套语法组织样式结构
- 使用变量管理主题色和关键样式

## SEO规范
- 使用语义化HTML标签
- 添加合适的meta标签
- 优化图片alt属性
- 实现合理的URL结构

## 性能优化
- 实现组件懒加载和代码分割
- 优化图片资源
- 实现合理的缓存策略
- 避免不必要的重渲染
